# TechCrush Cybersecurity Capstone Projects – Cohort 8

## Overview
This repository documents practical cybersecurity projects completed as part of the TechCrush Cybersecurity Capstone, Cohort 8.

The projects involved hands-on activities and collaborative work covering network security, secure data transmission, incident response planning, SIEM deployment, security monitoring, and controlled attack simulation.

## Projects

### 1. Networking and Securing Data Transmission
Designed and configured a small office network using Cisco Packet Tracer, implemented VLAN segmentation and Access Control Lists (ACLs), and explored secure communication using SSH, OpenSSL encryption, SCP, Nmap, and Wireshark.

### 2. Developing Incident Response Playbooks
Developed structured incident response playbooks covering phishing, ransomware, and Distributed Denial-of-Service (DDoS) incidents. The documentation included detection, containment, eradication, recovery, communication, and post-incident review procedures.

### 3. SIEM Deployment and Attack Simulation
Worked on a Splunk Cloud SIEM deployment involving Linux and Windows log collection, security event monitoring, and controlled attack simulations, including suspicious account creation, SSH brute-force attempts, and Windows Security log clearing.

**Participation note:** This was a collaborative capstone project. I actively participated in Projects 1 and 2. For Project 3, I participated in the initial implementation but could not complete the hands-on work due to insufficient system storage. I continued following up with the other team members until the project was completed.
